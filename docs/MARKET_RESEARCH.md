# 販売先・成功フォーマット調査

調査日: 2026-08-07。公開情報だけを使い、非公開の販売額や「最も売れている場所」を推測で断定していません。

## 採用判断

### 1. 直販の主基盤: Stripe Payment Links

Stripeは商品・単発決済・サブスクリプションをPayment Linksで販売でき、公式APIで商品、価格、決済リンクを作成できます。予約販売の日程やリリースIDをmetadataへ残し、Webhookで購入後処理へつなげられます。マーケットプレイスの自然流入はありませんが、販売条件、顧客体験、計測、更新を自分で管理できるため、自動化の主基盤に選びました。

Sources:
- https://docs.stripe.com/payment-links
- https://docs.stripe.com/api/payment_links/create

### 2. 日本語圏の発見経路: note

noteは有料記事とメンバーシップを持ち、日本語コンテンツの発見経路として有力です。一方、公式ヘルプは一般公開APIがないと明記しています。したがって、公開記事・無料プレビュー・購入導線の原稿は自動生成しますが、非公式APIやブラウザCookieを使った無人投稿は行いません。

Sources:
- https://note.com/info/n/nf3f7ff494105
- https://www.help-note.com/hc/ja/articles/46643492548121-note%E3%81%8C%E5%85%AC%E5%BC%8F%E3%81%A7%E5%85%AC%E9%96%8B%E3%81%97%E3%81%A6%E3%81%84%E3%82%8BAPI%E3%81%AF%E3%81%82%E3%82%8A%E3%81%BE%E3%81%99%E3%81%8B

### 3. 講座マーケットプレイス: Udemy

Udemyは公開ページで25万超のコース、8,000万人の受講生を掲げる大規模市場です。人気AI講座の公開ページでは「最新版」「初心者から」「具体的な成果」「継続更新」が繰り返し使われます。ただし、コース公開には講師画面と品質確認があり、一般の出品自動化APIを前提にしません。カリキュラムCSV、コース説明、プロモーション台本を出力し、最終審査は人が行います。

Sources:
- https://www.udemy.com/ja/teaching/
- https://www.udemy.com/course/2026notebooklmgoogle/
- https://www.udemy.com/course/ai-ozaken/

### 4. 紹介機能付き販売: Brain

Brainはノウハウ販売、レビュー、紹介機能を特徴とします。集客パートナーを作りやすい一方、調査した公式公開情報では一般向け出品APIを確認できなかったため、販売ページと紹介者向け説明の生成までにします。紹介文にも虚偽の体験談や収益保証を使いません。

Source:
- https://brain-market.com/

### 5. API自動出品オプション: Shopify

Shopify Admin GraphQL APIは商品管理、価格更新、販売チャネル公開を自動化できます。独自ストアを持つ段階で有効化し、品質・法務ゲート通過後だけACTIVEとして公開します。マーケットプレイスではないため、自然流入はnote・Udemy・検索・同意済みメールで補います。

Sources:
- https://shopify.dev/docs/api/admin-graphql/latest/mutations/productCreate
- https://shopify.dev/docs/api/admin-graphql/latest/mutations/productVariantsBulkUpdate
- https://shopify.dev/docs/api/admin-graphql/latest/mutations/publishablePublish

## 売れている講座から抽象化したフォーマット

特定作者の文章や教材はコピーせず、公開ランディングページに共通する構造だけを抽象化しました。

1. **対象を狭くする**: 「AI全般」より「調査」「営業」「社内業務」など、利用場面を一つに絞る。
2. **結果を先に示す**: 機能一覧ではなく、受講後に何を作れるかを明記する。
3. **初心者の不安を消す**: 前提知識、所要時間、つまずき、サポートを先に説明する。
4. **最新版である理由を示す**: 年号だけでなく、更新日、変更履歴、再検証箇所を残す。
5. **テンプレートと演習を付ける**: 視聴だけでなく、業務へ持ち帰れる成果物を用意する。
6. **証拠は実在するものだけ**: レビュー、人数、導入実績は取得後に追加し、AIで作らない。
7. **無料価値から有料価値へ**: 無料記事で判断基準を提供し、有料講座では実装、添削、運用まで提供する。
8. **予約販売を透明にする**: 未完成であること、提供開始、更新予定、価格、返金、変更時の連絡を明示する。

## 初期商品のポジショニング

「AI副業で稼ぐ」ではなく、企業・事業者が自社業務へ安全に実装する領域を選びました。成果物が測定可能で、誇大な収益訴求に依存せず、研修・伴走・テンプレート・継続更新へ展開しやすいためです。
