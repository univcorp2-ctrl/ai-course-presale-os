# 初期商品設計: AI業務フロー構築 実践ブートキャンプ

## 顧客

中小企業の経営者、事業責任者、バックオフィス・営業企画・カスタマーサポートの改善担当者。AIツールは試したが、社内データ、品質、費用、責任者、例外対応が曖昧で本番運用できない人を対象にします。

## 支払う理由

無料情報で得やすいのは機能説明とプロンプト例です。有料価値は次に置きます。

- 自社業務を選ぶ診断と、やらない判断
- 情報源・権利・鮮度を追跡する台帳
- モデル別の費用上限と機密性ルール
- 実装テンプレート、テスト、失敗時の停止
- 複数審査と人の責任を残す承認フロー
- 6週間で一つを完成させる提出物とQ&A

## 予約販売で検証する仮説

1. 「AIを学ぶ」より「自社の1業務を完成させる」の方が支払意思が高い。
2. 汎用プロンプトより、台帳・ルータ・品質ゲート・運用指標のセットが差別化になる。
3. 29,800円の予約価格は、個人学習と法人研修の間で意思決定しやすい。
4. 最初の50名を運用上限にすると、Q&A品質と改善データを確保できる。架空の希少性には使わない。

## 成功指標

売上だけでなく、価値提供を先行指標にします。

- 無料プレビューからカリキュラム閲覧への遷移
- 予約購入前の質問内容
- 第1週の業務選定シート提出率
- 最終ワークフロー完成率
- 作業時間、エラー率、レビュー差戻し率の改善
- 返金率、問い合わせ応答時間、更新満足度

## コンテンツ展開

- 無料: 課題選定、失敗パターン、比較表
- 予約商品: 6週間の実践講座
- 継続: 月次アップデート、事例分解、テンプレート追加
- 法人: 部門別ワークショップ、ルール策定、伴走導入

高額化は受講者の実績と運用負荷を確認してから行い、根拠のない値上げカウントダウンは使いません。
